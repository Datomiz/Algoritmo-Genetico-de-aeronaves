Esse código foi feito em 2022 para o projeto AeroJampa onde ele consiste em um Algoritmo Genético que produz o melhor projeto de aeronave referente a carga paga máxima (foco da competição SAE Brasil 2023).

Ele utiliza a teoria de diversos livros de aerodinâmica, controle e estabilidade, perfomance e projetos de aeronaves para chegar aos seus valores.

Além disso, é utilizado o Lifting Line Theory para conversão do Cl em CL para dados mais exatos, e ele utiliza também o métodos dos mínimos quadrados para ajuste de curva dos dados de perfis aerodinâmicos com base no XFOIL para aceleração dos cálculos

Por fim ele tem uma iterface simples feita em Tkinter para que o usuário possa alterar seus os parâmetros e utilizar o algoritmo.
